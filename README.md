# 项目介绍：screen-time（屏保时钟）

## 概述

`screen-time` 是一个极简的全屏屏保时钟 Web 应用。纯静态单文件实现，使用浏览器打开 `screensaver.html` 即可运行，无需任何构建工具或后端服务。

## 项目结构

```
screen-time/
└── screensaver.html    ← 唯一文件，包含 HTML + CSS + JavaScript
```

## 功能说明

### 核心功能
- **全屏时钟显示**：黑底白字，在屏幕正中央显示当前时间（`HH:MM:SS` 格式）
- **实时更新**：每秒刷新一次，精确到秒

### 彩蛋功能
- **彩虹文字效果**：每天 `13:00:00 ~ 13:00:59`（中午1点整的1分钟内），时间文字会显示流动的彩虹渐变动画

## 技术细节

| 项目     | 说明                                                           |
| -------- | -------------------------------------------------------------- |
| 语言     | HTML5 + CSS3 + 原生 JavaScript                                 |
| 字体     | Microsoft YaHei（微软雅黑），回退 sans-serif                   |
| 字号     | 72px，字重 300，字间距 6px                                     |
| 背景     | 纯黑 `#000`                                                    |
| 文字颜色 | 白色 `#fff`，彩虹模式下使用 CSS `background-clip: text` 渐变   |
| 动画     | `rainbow-flow`：`background-position` 从 `0%` 到 `200%` 循环  |
| 兼容性   | 使用 `user-select: none` 防止文字被选中；`-webkit-` 前缀兼容   |

## 运行方式

直接双击或在浏览器中打开 `screensaver.html` 文件即可。
